## ❓ 项目是什么？

### 一句话说明
**TradingAgents-CN** 是一个用多个AI Agents分析股票的平台，每个Agent扮演不同角色（基本面分析师、技术分析师等），他们互相讨论后给出投资建议。

### 核心创新
```
传统方式：一个AI处理所有任务 ❌
           容易出错，难以理解逻辑

我们的方式：多个专业AI Agents ✅
           基本面分析师 → 看财务
           技术分析师   → 看K线  
           新闻分析师   → 看事件
           情绪分析师   → 看舆论
           
           他们一起讨论，给出结论
```

### 能做什么？
- ✅ **单股分析** - 分析一只股票
- ✅ **批量分析** - 一次分析多只股票
- ✅ **股票筛选** - 找出符合条件的股票
- ✅ **模拟交易** - 虚拟炒股学习
- ✅ **学习中心** - 学习投资知识
- ✅ **报告生成** - 生成专业分析报告

## 🏗️ 核心技术栈

### 前端（用户界面）
```
Vue 3 + TypeScript
     ↓
Element Plus (UI组件库)
     ↓
Pinia (状态管理)
     ↓
Vue Router (页面路由)
     ↓
浏览器显示
```

### 后端（业务逻辑）
```
FastAPI (Python网络框架)
     ↓
LangGraph + LangChain (AI编排)
     ↓
MongoDB (数据存储)
Redis (缓存+队列)
     ↓
Uvicorn (服务器)
```

### AI引擎
```
多个 LLM 模型支持:
├─ OpenAI GPT-4
├─ 阿里通义千问
├─ DeepSeek
├─ Google Gemini
└─ 本地开源模型
```

### 数据源
```
股票数据：
├─ Tushare (A股)
├─ AKShare (多市场)
├─ BaoStock (A股)
├─ Finnhub (美股)
└─ Yahoo Finance (全球)
```
