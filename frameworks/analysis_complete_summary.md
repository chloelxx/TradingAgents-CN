## 💡 关键要点速记 (1分钟版)

### 系统架构

```
Request → Router → Service → Model → Database → Response
          ↓                                      ↓
        验证                               后台任务
```

### 核心特性

- 异步处理（立即返回，后台执行）
- 实时推送（WebSocket/SSE进度更新）
- 并发控制（用户5个，全局20个）
- 多源数据（Tushare/AKShare/BaoStock）
- 多智能体（市场、基本面、新闻、社媒分析）

### 关键文件

- `routers/analysis.py` (1259行) - 分析API
- `services/analysis_service.py` (955行) - 分析逻辑
- `services/queue_service.py` (364行) - 队列管理
- `routers/config.py` (2100行) - 配置管理
